# カリフォルニア住宅価格予測パイプライン構築とモデル解釈
〜線形モデルの限界検証からLightGBMによる精度改善、Feature Importanceの多角的評価まで〜

## 1. プロジェクト概要
カリフォルニア州の住宅国勢調査データ（20,640件）を用い、住宅価格の中央値を高精度に予測する機械学習パイプラインを構築しました。
単なる精度の追求にとどまらず、**「データリークの厳格な防止」「線形モデルの数理的限界の検証」「決定木モデルにおける変数重要度のバイアス補正」**といった実務上の要所を意識した検証を行っています。

---

## 2. 実装上の工夫と技術的アプローチ

### ① データリークを防ぐ交差検証パイプライン（Nested CV構造）の自作
- 単純な事前標準化（前処理）によるカンニングを防ぐため、Fold内の学習データのみでスケーリングを行う `evaluate_cv` 関数をモジュール化。
- ハイパーパラメータ探索（`RidgeCV` / `LassoCV`）においても、外側の検証データに情報が漏洩しない厳密な検証設計を担保。

### ② データの特性把握と残差分析（Ceiling Effectの特定）
- 予測値と実測値の散布図（OOF予測）を作成し、誤差の出方を可視化。
- 実測値が \$500,000 付近で予測値が垂直に散らばる現象を確認し、元データにおける「上限打ち切り（Ceiling Effect）」の存在を特定。

### ③ 線形モデルの限界から非線形モデル（LightGBM）への移行
- 正則化（L1/L2）を施しても線形モデルでは $R^2 \approx 0.641$（MAE 約 \$49,560）が上限となることを確認。
- 地理情報（緯度・経度）などの非線形な関係を捉えるため LightGBM を導入し、$R^2 = 0.850$（MAE 約 \$29,401）まで精度を大幅に改善（誤差を約 \$20,000 削減）。

### ④ 変数重要度（Feature Importance）のバイアス補正
- デフォルトの分岐回数基準（`split`）では、値の種類が多い連続変数（緯度・経度）が見かけ上高く評価される「High Cardinality Bias」が発生することを確認。
- 純粋な予測誤差の削減量を測る `gain` 基準で重要度を再算出し直すことで、ドメイン知識（不動産価格には所得水準が最も強く寄与する）と整合する結果（`median_income` が寄与度1位）を数理的に証明。

## 3. モデル検証結果

| モデル | 検証手法 | 全体 $R^2$ | 平均 MAE (\$) | 特記事項 |
| :--- | :--- | :--- | :--- | :--- |
| **線形回帰** | 5-Fold CV | 0.6414 | \$49,574.43 | ベースライン |
| **RidgeCV** | 5-Fold CV | 0.6415 | \$49,568.03 | 最適 $\alpha \approx 10.0$ |
| **LassoCV** | 5-Fold CV | 0.6417 | \$49,560.11 | 最適 $\alpha \approx 64.0$（不要な特徴量の圧縮） |
| **LightGBM** | 5-Fold CV | **0.8501** | **\$29,401.72** | **非線形モデルによる精度限界突破** |
