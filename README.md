# California Housing — 地区の住宅価格中央値の予測

カリフォルニアの20,640地区について、収入・住宅構成・立地から
地区の住宅価格中央値を予測した分析です。

## 主な結果

同じテスト用4,128地区で評価しました。

| モデル | MAE（ドル） | R² |
|---|---:|---:|
| 学習データの中央値を一律に予測 | 87,403.99 | -0.050 |
| 線形回帰（元の9特徴量） | 50,670.49 | 0.625 |
| LightGBM（作成した特徴量を含む14特徴量） | 27,845.63 | 0.842 |

LightGBMは中央値予測に比べ、MAEを約68%削減しました。
一方、記録上限に達した179地区では、平均62,328.43ドルの
過小予測が残りました。

## 分析の流れ

- 学習用80%・テスト用20%に分割
- 学習データの欠損、価格分布、相関を確認
- Pipelineで欠損補完とカテゴリ変換を実施
- 5分割交差検証でモデルと設定を比較
- 世帯当たりの部屋数・人口、寝室比率、LA・SFまでの距離を追加
- 置換重要度と価格帯別の誤差を確認
- 選択したLightGBMをテストデータで評価

## 評価上の制約

- 同じテストセットを学習序盤のモデル評価でも参照しています。
- 住宅価格には500,001ドルの記録上限があります。
- ランダム分割での評価です。未観測地域や将来の市場での性能は
  別途検証する必要があります。

## 実行方法

1. california_housing_portfolio.ipynb をGoogle Colabにアップロードする。
2. セルを先頭から順番に実行する。

データはNotebook内のURLから取得します。
交差検証と特徴量重要度の計算には数分かかる場合があります。
